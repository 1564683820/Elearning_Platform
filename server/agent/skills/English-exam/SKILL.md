# 英语试卷生成专家 Skill

> English Exam Paper Generator: 基于真实考试题型与结构，一键生成贴近真题的试卷。
> 核心流程：`确认年级 → 选择/确认模板 → 生成试卷内容 → 输出试卷 + 选择题JSON`

---

## 一、年级与考试类型

### 小学 (Primary School)

- **适用年级**：3-6 年级
- **词汇量**：课标核心词汇 400-700 词
- **题型池**：选出不同类的一项、单项选择、连词成句、情景对话、完形填空（短文）、阅读理解（1-2 篇）、小作文（5-8 句）
- **阅读理解文章长度**：每篇 80-150 词
- **整体难度**：句子简单，时态以一般现在时、现在进行时为主

### 初中 (Junior High / 中考)

- **适用年级**：7-9 年级（含中考模拟）
- **词汇量**：课标词汇 1500-2000 词
- **满分**：120 分
- **考试时间**：90-100 分钟

#### 中考笔试题型

> 以下为中考笔试部分的标准题型结构，初中三个年级（七年级/八年级/九年级）的常规考试均采用此格式。

| 序号 | 题型 | 题量 | 每题分值 | 小计 | 说明 |
|:---|:---|:---|:---|:---|:---|
| 1 | 单项填空 | 15题 | 1分 | 15分 | 语法词汇4选1 |
| 2 | 完形填空 | 10题 | 1分 | 10分 | 短文10空4选1 |
| 3 | 阅读理解 | 3篇（每篇5小题） | 2分 | 30分 | A篇应用文 + B篇说明文 + C篇配对阅读 |
| 4 | 短文填空 | 10题 | 1.5分 | 15分 | 开放填空，无选项，不给首字母 |
| 5 | 读写综合 | A.信息归纳5题(5分) + B.书面表达1题(15分) | — | 20分 | 书面表达80-100词（发言稿/书信/日记/倡议书） |
| **合计** | — | **51小题** | — | **90分** | 笔试部分，不含听力30分 |

#### 题型池（含听力）

1. 听力理解（听单句话、听对话、听独白、听填信息）
2. 单项填空（语法词汇4选1）
3. 完形填空（短文10空4选1）
4. 阅读理解（A/B篇各5题4选1 + C篇配对阅读）
5. 短文填空（开放填空，无选项）
6. 读写综合（信息归纳5题 + 书面表达80-100词）

- **阅读理解**：A篇实用信息/应用文，B篇说明文，C篇配对阅读
- **短文填空**：不给首字母提示，考查冠词/介词/连词/代词/名词/动词/形容词的综合运用
- **书面表达**：发言稿/书信/日记，80-100词

### 高中 (Senior High / 新课标高考)

- **适用年级**：高一至高三（含高考模拟，新课标Ⅰ卷结构）
- **词汇量**：课标词汇 3500+ 词
- **满分**：150 分
- **考试时间**：120 分钟

#### 高考笔试题型（新课标Ⅰ卷）

> 以下为高考笔试部分的标准题型结构，高中三个年级（高一/高二/高三）的常规考试均采用此格式。

| 大题 | 小节 | 题量 | 每题分值 | 小计 | 题号范围 | 说明 |
|:---|:---|:---|:---|:---|:---|:---|
| 第二部分 阅读（共两节，满分50分） | 第一节 | 4篇，15小题 | 2.5分 | 37.5分 | 21-35 | A篇应用文+B篇记叙文+C篇说明文+D篇议论文各1篇 |
| | 第二节（七选五） | 1篇，5小题 | 2.5分 | 12.5分 | 36-40 | 7个选项选5个填入文中空白处 |
| 第三部分 语言运用（共两节，满分30分） | 第一节 完形填空 | 1篇，15小题 | 1分 | 15分 | 41-55 | 短文15空4选1 |
| | 第二节 语法填空 | 1篇，10小题 | 1.5分 | 15分 | 56-65 | 有提示词6-7空+无提示词3-4空 |

| | 第二节 读后续写 | 1题，150词左右 | 25分 | 25分 | 无题号 | 给定前文+2段首句，续写2段 |
| **合计** | — | **46小题** | — | **120分** | — | 笔试部分，不含听力30分 |

#### 题型池（含听力）

1. **听力**（短对话5段 + 长对话4段 + 独白1段，共20题，题号1-20，含在总分150分中但笔试按120分计）
2. **第二部分 阅读（共两节，满分50分）**
   - 第一节 阅读理解（4篇A/B/C/D，共15题，题号21-35）
   - 第二节 七选五（1篇5题，题号36-40）
3. **第三部分 语言运用（共两节，满分30分）**
   - 第一节 完形填空（1篇15空4选1，题号41-55）
   - 第二节 语法填空（1篇10空，含提示词+无提示词混合，题号56-65）
4. **第四部分 写作（共两节，满分40分）**：无题号
   - 第一节 应用写作（80词左右，15分）
   - 第二节 读后续写（150词左右，25分）

- **阅读理解题材**：应用文（广告/指南）、记叙文（人物故事）、说明文（社会/科技/文化）、议论文（学术研究/观点）
- **七选五**：选材为说理性文章（自我成长/心理健康/学习方法等）
- **语法填空**：6-7题有提示词（动词语态/时态/非谓语/词形变化），3-4题无提示词（冠词/介词/连词/关系代词）
- **读后续写**：记叙文，侧重人物心理描写、动作描写、环境描写

### 大学英语四级 (CET-4)

- **词汇量**：约 4500 词
- **题型池**：写作、听力（短篇新闻/长对话/短文）、选词填空、长篇阅读（段落匹配）、仔细阅读、翻译（段落汉译英）

### 大学英语六级 (CET-6)

- **词汇量**：约 6000 词
- **题型池**：写作、听力（长对话/短文/讲座讲话）、选词填空、长篇阅读（段落匹配）、仔细阅读、翻译（段落汉译英）

## 三、阅读理解文章生成标准

### 段落数硬性要求

| 学段 | 每篇词数 | 最少段落数 | 每段最少句数 |
| :--- | :------- | :--------- | :----------- |
| 小学 | 80-150词 | 2段 | 3句 |
| 初中A篇（应用文） | 150-250词 | 2-3段 | 3句 |
| 初中B篇（说明文） | 250-350词 | 4段 | 5句 |
| 高中A篇（应用文） | 200-280词 | 3段 | 4句 |
| 高中B/C/D篇 | 280-350词 | 4段 | 5句 |
| 四六级仔细阅读 | 300-450词 | 4段 | 5句 |

### 段落功能模板（4段结构）

| 段落 | 功能 | 内容要求 |
| :--- | :--- | :------- |
| P1 | 引入话题 | 介绍主题/人物/现象，说明背景和重要性 |
| P2 | 展开论述 | 解释原理/机制/原因/发展过程，3-4个具体细节 |
| P3 | 转折/新发现 | 新研究/相反观点/意外结果/具体案例 |
| P4 | 深化/结论 | 影响/应用/意义，总结观点，指出不足或展望 |

> ⚠️ **禁止单段文章**。每段必须写满至少5句。不允许出现"一句话段落"。

### 阅读理解考点覆盖（每题标注考点类型）

每篇阅读理解的设问必须覆盖以下考点：
- **细节理解**：直接信息定位（至少2题）
- **推理判断**：推断隐含信息（至少1题）
- **主旨大意**：标题/中心思想/写作目的（至少1题）
- **词义猜测**：生词/代词语境义（至少1题）

## 四、各题型生成规范

### 初中—短文填空（开放填空）

- 10个空格，不给首字母，不给选项
- 答案必须唯一确定（不能多解）
- 考查点分布：冠词(1)、介词(1)、连词(2)、代词(1)、名词(1)、动词(1)、形容词/副词(1)、固定搭配(2)
- 文章长度：200-250词
- 示例：
  ```
  Last winter holiday, I visited a village with only 11 houses. __71__ 
  the village was very small, I spent a whole day in it.
  // 答案：71. Although/Though
  ```

### 初中—配对阅读（C篇）

- 左栏：5个具体问题/需求（每个2-3句）
- 右栏：7个建议/方案（A-G，每个3-4句）
- 其中2个选项为多余干扰项
- 要求：左栏和右栏必须用不同的语言表述同一概念（同义改写）

### 高中—七选五

- 文章主题：说理性文章（自我成长/学习方法/人际关系/心理健康等）
- 7个选项（A-G），每个选项是**一句完整的英文句子（主谓结构）**，其中2个多余干扰项
- 空格位置：段首、段中、段尾各至少1个
- 干扰项特征：与文中某处词汇相似但逻辑不通；过于宽泛或片面
- **重要**：选项是完整的英语句子，不能是单词或短语

#### 真实生成示例

以下是一篇关于"自我原谅"(self-forgiveness)的七选五文章结构示例：

- 文章约400-500词，分4-5段，内容围绕自我成长与自我接纳
- 文中有5处空白，题号为36-40（格式为 `____36____`）
- 7个选项（A-G）示例（注意：不要包含"A. ""B. "等前缀，只需纯文本）：
  - A little self-forgiveness also goes a long way.
  - Now list all the characteristics you like about yourself.
  - They might even like to have a go at doing the exercise.
  - It's just as important to show yourself some forgiveness.
  - It doesn't mean you have to ignore what's happened or forget it.
  - Whatever it is, no matter how small it might seem, write it down.
  - Whatever the mistake, remember it isn't a fixed aspect of your personality.
- 正确答案示例：C, B, F, A, G（其中D和E为干扰项）
- 文章空白分布：段首设置1-2个（引出下文），段中设置2-3个（逻辑衔接），段尾设置1个（总结呼应）

### 高中—完形填空

- 一篇约400-500词的叙事或说明文，设15空，每空4选1（A/B/C/D）
- **首句不设空**，空格间距至少5个词以上
- **【重要】文章正文中每个空位必须嵌入____标记（不可遗漏）**，例如："Tom ____ a high school student who always ____ a passion for science."
- 考查点分布：时态变化(3-4)、词义辨析(4-5)、固定搭配(2-3)、介词辨析(1-2)、非谓语动词(1-2)
- 选项设计：每空4个选项必须用**真实英语词汇/短语**，不能是占位符
- 干扰项要具有迷惑性，不能明显错误

#### 真实生成示例

以下是一篇关于"Melanie Bailey助人完成马拉松"的完形填空结构示例：

- 文章约220词，讲述一位女选手在比赛中帮助受伤同伴的故事
- 15个空（题号41-55），options为二维数组，每空一组4个选项
- 选项示例（前5空）（注意：不要包含"A. ""B. "等前缀，只需纯文本）：
  - 第1空（谓语动词）：["finished", "designed", "followed", "changed"]
  - 第2空（名词辨析）：["delay", "chance", "trouble", "excuse"]
  - 第3空（名词辨析）：["judge", "volunteer", "classmate", "competitor"]
  - 第4空（名词辨析）：["race", "school", "town", "training"]
  - 第5空（谓语动词）：["agreed", "returned", "stopped", "promised"]
- 正确答案示例：D, A, D, A, C（对应"changed, delay, competitor, race, stopped"）
- 干扰项设计原则：时态干扰（finished/designed/followed vs changed）、语义干扰（judge/volunteer/classmate vs competitor）、搭配干扰（agreed/returned/promised vs stopped）

### 高中—语法填空

- 10个空，有提示词6-7个，无提示词3-4个
- 提示词考点：动词时态语态、非谓语动词（to do/doing/done）、名词单复数、形容词比较级/最高级、词性转换
- 无提示词考点：冠词、介词、连词、关系代词
- 文章题材：中国传统文化/人物故事/科技发展/社会现象

### 高中—读后续写

- 提供350词以上的记叙文前文，不要分过多段落（建议3-4段），避免每段过短
- 前文必须有完整的情节发展、人物情感变化和冲突转折
- 段落开头语已给出2句（不能改动）
- 续写2段，总词数150词左右
- 评分要点：内容连贯性(5分)、语言丰富性(5分)、逻辑衔接(5分)、情感深度(5分)、书写规范(5分)，共25分
- 续写必须包含：动作描写、心理描写、环境烘托、对话/间接引语

### 写作（书面表达）

| 学段 | 类型 | 词数 | 必须给出 |
| :--- | :--- | :--- | :------- |
| 初中 | 发言稿/书信/日记/倡议书 | 80-100词 | 中文情景提示、要点清单、开头结尾句 |
| 高中-应用写作 | 回信/报道/评论文/邮件/通知/演讲稿 | 80词左右 | 中文情景描述、要点要求、开头结尾格式 |
| 高中-读后续写 | 读后续写 | 150词左右 | 前文(350词以上)+2段首句（给定不可改动） |

## 五、试卷生成流程

1. **确认年级与考试类型**
   若用户未明确，询问："请问需要生成哪个年级/考试的试卷？（小学/初中/高中/四级/六级）"

2. **确认题型模板**
   询问用户是否需要自定义题型和数量。若用户说"默认"或直接跳过，则采用上述内置模板。

3. **一键生成试卷**
   基于确定的模板和年级，一次性生成全部题目。试卷必须包含：
   - 试卷标题（如"2026年广东省初中英语学业水平模拟考试"）
   - 考试时间、满分分值、答题注意事项
   - 各大题，标清题号、分值、答题要求
   - 大题用中文序号（第二部分 阅读、第三部分 语言运用、第四部分 写作）
   - 小节用中文序号（第一节、第二节）
   - 小题从21开始用阿拉伯数字连续编号（听力占用1-20）
   - 阅读理解文章完整呈现且分段正确
   - 书面表达给出清晰的中文提示和要求

4. **输出 Markdown 格式试卷**

5. **【新增】输出选择题JSON**（见第七节）

## 六、题目质量要求

- 所有题目必须为原创，基于通用知识点重新编写，避免直接抄袭真题
- 选项设计合理，干扰项具有迷惑性，符合学段认知水平
- 语法、拼写、标点无误
- 阅读理解设问覆盖 细节理解/推理判断/主旨大意/词义猜测 四大考点
- 听力题干简洁明确，选项长度相近
- 完形填空首句不设空，空格间距至少5个词以上
- 语法填空有提示词的比例控制在60%-70%
- 七选五选项必须有两个明确的多余干扰项
- **【重要】不要在选项文本中包含字母前缀（如"A. ""B. "等），系统会自动添加，只需提供纯文本内容**

### 字段说明

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `title` | string | 试卷标题 |
| `grade` | string | 学段：`junior_high`/`senior_high`/`primary`/`cet4`/`cet6` |
| `total_score` | number | 试卷满分 |
| `duration_minutes` | number | 考试时长（分钟） |
| `choice_questions` | array | 所有选择题数组 |
| `choice_questions[].question_number` | int | 题号（与试卷中一致，整卷连续，从21开始） |
| `choice_questions[].section` | string | 所属大题名称 |
| `choice_questions[].question_type` | string | `single_choice` / `match` / `seven_choice` |
| `choice_questions[].correct_answer` | string | 正确答案（大写字母：A/B/C/D/E/F/G） |
| `choice_questions[].option_count` | int | 选项数量 |
| `choice_questions[].options` | string[] | 选项内容列表（选项字母 + 内容，或纯字母用于配对/七选五） |
| `choice_questions[].score` | float | 该题分值 |

### ⚠️ 篇章类题型的展开规则（重要）

完形填空和七选五生成时对应一条 LLM 数据记录（含一篇短文），但输出到 choice_questions 时必须**展开为每条空白独立的一条记录**：

| 内部 type | 分类 | 展开方式 |
| :--------- | :--- | :------- |
| `cloze` | 完形填空 | N个空白 → N条 `single_choice`，每条共享4选1，分数均分 |
| `seven_choice` | 七选五 | 5个空白 → 5条 `single_choice`，每条共享7选项(A-G)，分数均分 |
| `reading` | 阅读理解 | M道子题 → M条 `single_choice`，每条独立选项 |
| `grammar_fill` | 语法填空 | ❌ 不包含在选择题JSON中（填空类题型，无选项） |

### 必须生成 JSON 的题型

| 题型 | 包含在 JSON 中 | question_type |
| :--- | :--- | :--- |
| 听力—短对话/长对话/独白（选择题） | ✅ | `single_choice` |
| 单项填空（语法单选） | ✅ | `single_choice` |
| 完形填空（4选1） | ✅ | `single_choice`（每空一条） |
| 阅读理解（4选1） | ✅ | `single_choice` |
| 七选五 | ✅ | `single_choice`（每空一条，共5条） |
| 配对阅读 | ✅ | `match` |
| 听力—听填信息（填空） | ❌ 不包含 | — |
| 短文填空（开放填空） | ❌ 不包含 | — |
| 语法填空 | ❌ 不包含 | — |
| 阅读—信息归纳 | ❌ 不包含 | — |
| 书面表达/写作 | ❌ 不包含 | — |
| 读后续写 | ❌ 不包含 | — |
