# 视觉风格：工程蓝图 (Blueprint)

> 参考 ppt-master 蓝图风格，适用于工程/科学/方法论类课程，理工科教学场景。

## 形状语言
- **卡片形状**: sharp（直角，科技感线框风格，`card_radius: 0px`）
- **装饰元素**: 线框节点 + 工程标记 + 测量标注 + 左侧色标
- **阴影层级**: none（纯扁平线稿设计）
- **标记圆角**: 0px，宽度 3px

## 排版性格
- **标题字体**: `'Courier New','Source Code Pro','Microsoft YaHei Mono',monospace`
- **正文字体**: `'Inter','SCDream','Microsoft YaHei',sans-serif`
- **字号**: 标题 24px / 正文 13px / 注释 10px
- **字重**: 标题 Bold / 正文 Normal

## 色彩使用原则
- 主色用于：线框节点、十字标、高亮连接线
- 辅色用于：次要标注、虚线标记
- 背景色：深蓝黑底色（#1a1f2e 或主题深色），白色线条
- 文本色：以白色/浅蓝为主，白色线上标注

## 留白与间距
- 页面边距: 50px
- 元素间距: 8px（紧凑工程风格）
- 卡片间距: 8px
- 行高: 1.4（紧凑）

## 装饰 DNA
- 顶部色条: 无（工程边框线替代）
- 标题左侧色标: 有（十字标节点样式）
- 背景装饰: 网格线（20px 间距蓝线 opacity 0.1）+ 十字标点缀
- 分隔线: 工程虚线（engineering-dashed），带十字节点
- 页码: 显示（工程标注风格）

## 适用场景
- STEM/理工科教学内容
- 方法论/流程图展示
- 实验操作步骤
- 技术类课程（编程、工程、物理）
