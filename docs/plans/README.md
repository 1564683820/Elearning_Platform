# 开发方案归档

项目开发过程中明确要求输出的开发方案默认保存在本目录。根据方案的主要实施目标选择一个分类，首次使用该分类时创建子目录。

| 分类 | 适用范围 |
|---|---|
| `features/` | 新功能、功能迭代和跨端业务实施 |
| `architecture/` | 架构调整、代码重构和工程规范落地 |
| `fixes/` | 故障修复、兼容性修复和性能优化 |
| `testing/` | 专项测试、回归和验收方案 |
| `deployment/` | 部署、环境切换、数据迁移和发布回滚 |

新建方案默认使用 `YYYY-MM-DD-主题.md`。同一事项优先更新已有方案。已存在于其他文档目录的方案可以继续在原路径维护。用户指定的路径和格式优先。

方案内容至少写清目标、影响范围、实施步骤和验证方式。关联的 PRD、设计稿和工程 Change Audit 可在方案中链接。请求处于方案阶段时，交付方案文件和会话摘要。
