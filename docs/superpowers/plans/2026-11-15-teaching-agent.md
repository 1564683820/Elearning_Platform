# 教学任务 Agent 实施计划

目标是支持教师从班级学情出发，检索校本教材，生成复习教案与练习，经审核后发布到已有考试模块。

采用现有 React、FastAPI、MySQL、Milvus，新增 LangGraph 编排与持久任务记录。业务工具复用现有学情、RAG、记忆及试卷服务。

## 交付任务
