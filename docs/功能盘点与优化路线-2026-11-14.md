# Elearning 功能盘点与优化路线

日期：2026-11-14。阶段：代码盘点与开源调研；不是功能验收报告。所有优化项均为待实施建议，不能据此声称已实现。

## 目标、边界与依据

目标：先识别项目实际具备的功能，为每项功能提出可实施、可验证的优化，再分批落地。覆盖教师 Web、学生/教师小程序、管理者后台及共用服务。

非目标：本轮不替换技术栈、不整体搬入第三方 LMS、不操作生产数据库、不将宣传页面或原型当成已实现功能。

关键假设：保留 React/Vite、FastAPI、原生微信小程序；优先保证教学闭环正确性和可恢复性，再提高智能化与视觉表现。

证据：`client/src/App.tsx` 有 35 个带 path 的 Route 声明（包括重定向与通配符）；`client/miniprogram/miniprogram/app.json` 注册 55 个页面，均存在对应 JS；AST 静态扫描 `server/app/api/v1/*.py` 得到 308 个 HTTP/WebSocket 装饰器声明。声明数不等于运行时注册或可用接口数，且不包含其他路由目录。

状态解释：下表“现有”指发现页面、接口或服务代码，尚未证明端到端可用；“建议”指改进方向，不代表当前一定缺失。数据库与外部服务尚未形成完整验收环境，因此性能、识别准确率、模型效果都不作未经测量的结论。

## 已经定位的优化切口

1. `client/src/pages/ManualGrade/index.tsx:140` 独立定义 `/api/v1`，而共享 `api/client.ts` 使用 `/Elearning/api/v1`。先核对部署转发，再统一请求入口及错误处理；不要只改字符串后声称全链路通过。
2. 小程序 `pages/teacher/scan/index.js` 使用 `/scan-progress` 与 `/scan`；浏览器移动页使用 `/scan-grade`。应通过同一张样本逐字段比对再收敛，两者并非已经统一。
3. `word_service.py:324` 当前进度更新掌握等级、复习次数与最后复习时间。到期调度可从此增量扩展；不能把“记录学习进度”等同于具备 FSRS 调度。
4. `upload_job_manager.py` 有 Redis + 内存回退和两小时 TTL。需验证重启与跨进程状态，不能把“显示进度”当成持久任务恢复。
5. `client/miniprogram/miniprogram/utils/api.js` 写死 HTTP 后端地址；注释说 Token 仅内存，但实现会读写 Storage。应先统一环境配置与会话语义，再做离线体验。
6. `Teaching/index.tsx` 的“更多功能”明确为 coming，应排除在已实现业务功能之外。登录页手机示意图也是展示内容，不是产品能力。
7. `server/app/main.py` 启动生命周期会建表并补字段；上一轮发现数据库服务停止和配置缺失。先完成可重复本地环境与测试数据库，再启动需写入的集成验收。

## 优化顺序与取舍

可选路线：A 按页面逐个美化，用户感知快但跨端正确性问题仍会保留；B 按教学闭环改进，覆盖“资料→出题→作答→批改→错题→复练→报告”；C 替换为整套 LMS，迁移成本和业务风险最高。

建议 B，先做共用环境与正确性，再贯通学习效果。此为建议，尚不是各子项目的详细设计审批或开源依赖安装授权。

| 批次 | 范围 | 交付及退出标准 |
|---|---|---|
| 0 | 环境、数据库预检、配置隔离、测试能力 | 在可丢弃数据库完成启动和健康验证；明确禁止自动操作生产；有测试运行入口 |
| 1 | F01/F03/F17/F19–21/F30/F32–33 | 身份矩阵、成绩事务、扫描防重与低置信复核设计；用异常与并发样本验收 |
| 2 | F15–16/F18/F22 | 题目版本、发布快照、模板坐标、错题同步；考试与复练往返一致 |
| 3 | F05–14/F24 | 学习日志、复习调度、练习与口语反馈；用固定样本与真实真机验证 |
| 4 | F23/F25–29 | 文档引用、任务恢复、知识图谱与课件一致性；模型失败可恢复、成本可追踪 |
| 5 | F02/F04/F31/F34 及各端体验 | 指标口径、性能、可访问性、空态错误态；统一完整回归 |

## 后续实施约束

每项优化独立维护状态（未设计、已设计、实施中、自动验证通过、环境验收通过），不得以一个模块通过编译代表功能完成。每批先给出受影响文件、接口兼容策略、测试样本、回退方式及 Audit，再实施。

本轮尚未测量真实答题卡识别率、语音延迟、RAG 命中率与成绩事务一致性；这些需要脱敏样本及可用测试环境。目标持续有效，本文完成盘点阶段，不表示全项目优化完成。
