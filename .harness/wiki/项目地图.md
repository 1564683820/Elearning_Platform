# 项目地图

## 项目说明

- 项目名称：Elearning。
- 当前组织：工程治理、产品资料、服务端和客户端各有独立目录。根目录保留仓库级文档和脚本。
- 仓库形态：单仓库、多运行时，不是 npm/Python 标准 workspace。
- 主要用途：英语学习、教师教学管理、试卷与批改、AI 助手、教材/词库与多媒体处理。

## 主线目录

- `.harness/`：`AGENTS.md`、`.agent/`、`skill/`、`rules/`、`wiki/` 和工程审计。
- `product/`：PRD、设计稿和产品需求变更。
- `server/app/`：`main.py` 组装 FastAPI，`api/v1/` 和 `routers/` 存放路由，`services/` 承载服务，`models/` 和 `schemas/` 分别是 ORM 模型和 Pydantic 契约。
- `server/database/alembic/`：主应用迁移及版本，已应用的版本不可原地改写。
- `server/database/alembic_agent/`：隔离演示库的独立冻结迁移链，对应 `server/database/alembic-agent.ini`。
- `server/app/teaching_worker.py`：教学任务 Worker，使用 Streams/outbox、SQL 检查点和租约恢复。业务入口为 `/api/v1/teaching-tasks`。
- `client/`：React 18 + TypeScript + Vite 管理端，源码位于 `src/`，请求封装位于 `src/api/`。
- `client/miniprogram/`：微信小程序项目入口，前端源码位于其 `miniprogram/` 子目录。
- `server/cloudfunctions/miniprogram/` 和 `server/cloudfunctions/import-dict/`：分别用于小程序云函数和独立词库导入。修改前确认部署目标。
- `server/deploy/`：Docker、Compose、Nginx 和 Supervisor 配置。
- `scripts/`：数据导入、字典、PPT 和分析类一次性/运维脚本，部分脚本会改变数据。
- `data/`、`uploads/`：本地数据和运行/导出文件，不是业务源码。
- `docs/`：项目文档，不当然代表当前运行事实。

## 未迁入的旧项目内容

- 虚拟环境、`node_modules`、构建产物、上传物、日志、调试图片和大型导入数据未迁入。
- `prototype/`、`Create_Figma_Design_temp/`、`figma_design_extracted/` 和 `admin_contrl/` 等原型/历史目录未迁入。
- 旧项目的多平台 Agent 规则目录未迁入；本项目以 `.harness/` 为唯一治理真源。
- 旧生产环境文件、含明文凭据的初始化脚本与本机小程序私有配置未纳入版本库。

## 技术栈与基础设施

- 后端：Python 3.10+、FastAPI、Uvicorn、Pydantic 2、SQLAlchemy 2、Alembic。Dockerfile 使用 Python 3.12。
- Web：React 18、TypeScript 5、Vite 5、Axios、React Router、Recharts。
- 小程序：微信小程序原生 JS/WXML/WXSS，可在云开发和自建 HTTP API 间切换。
- 数据：MySQL 主库与单词库、Redis、Milvus；Milvus 依赖 etcd 和 MinIO。
- 外部能力：微信、对象存储、LLM/Embedding/多模态、TTS、PDF 解析和视频生成等，均需外部凭据或服务。

## 契约与调用链

- FastAPI 公开路由统一挂载在 `/api/v1`。
- Web 端 API 主封装为 `client/src/api/client.ts`。仍存在局部硬编码 URL，修改部署前缀时必须全局检索。
- 小程序数据抽象主入口是 `client/miniprogram/miniprogram/utils/api.js`，当前默认使用自建 HTTP API。
- 项目当前没有被证实的 OpenAPI 客户端自动生成链路；修改契约需人工同步检查 Web 和小程序。

## 生成物和禁止手改路径

- `client/dist/**`：Vite 构建产物，必须由构建命令生成。
- `**/node_modules/**`、`**/__pycache__/**`、`*.tsbuildinfo`：工具缓存和依赖。
- 各级 `uploads/**`：运行数据。服务默认使用 `server/uploads/`，旧工作区可继续使用既有 `backend/uploads/`。
- `server/database/alembic/versions/**`：已应用迁移不可原地编辑。数据库变更应新建版本。

## 统一命令

从仓库根目录运行：

- 查看帮助：`task help`
- 安装依赖：`task setup`
- 启动后端：`task dev-backend`
- 启动 Web：`task dev-web`
- 后端快速回归：`task test`
- 后端行为回归：`task unit`（unittest，含 SQLite 事务与外部服务替身，不等于在线集成验收）。
- 教学环境检查/Worker：`task check-teaching`、`task dev-worker`。
- Web 类型检查：`task typecheck`
- Web 构建：`task build`
- Harness 结构检查：`task lint`
- 非写入综合验证：`task verify`（Harness 自检、后端语法、Web 类型检查）

当前已有 `server/tests/` unittest 回归，可通过 `unit` 执行。`test` 只做 Python 语法回归，`lint` 只做 Harness 结构检查。教学任务启动与验收见 `docs/教学任务工作台-启动与验收.md`。

## 环境配置

- 后端配置模型：`server/app/core/config.py`。
- 后端本机环境文件：`server/.env`，由 Git 忽略。
- 基础设施本地编排：`server/deploy/docker-compose.yml`，MySQL 需要单独运行。
- 小程序项目配置：`client/miniprogram/project.config.json`。`project.private.config.json` 为本机配置。
- MCP 当前仅配置 CloudBase，见 `.mcp.json`；配置不包含生产授权。

## 开发、测试与生产差异

- Web 开发由 Vite 代理 API；生产路径还包含 `/Elearning/api/v1` 前缀。
- 小程序 `utils/api.js` 包含当前运行模式与后端地址，变更前必须确认目标环境。
- 完整后端运行依赖 MySQL、Redis、Milvus 及多个外部服务；语法编译不等于集成验证。

## 已知未落地或待治理项

- `server/pyproject.toml` 与 `server/requirements.txt` 已有依赖版本漂移，当前安装真源为 `requirements.txt`。
- 已有后端 unittest 和单独的教学任务 Playwright 脚本；未配置完整前端测试平台、Python/TypeScript Lint 或 CI workflow。
- 应用签名与加密密钥由本地环境或部署环境注入，缺失或为空会导致配置加载失败。Redis 和 MinIO 的 Compose 凭据通过 `--env-file server/.env` 注入。
