# 安全规则

## 适用范围

适用于凭据、认证、授权、支付、上传、用户数据、外部 AI/存储服务、`server/deploy/**`、`.mcp.json` 和环境配置。

## 必须

- 真实凭据仅通过本机 `.env`、部署平台 Secret 或等价密钥管理机制提供，可提交文件只允许空值或明显的非生产占位符。
- 鉴权/授权变更要分别验证未登录、普通用户、教师和管理员等相关身份，不仅验证成功路径。
- 上传功能校验类型、大小、文件名/路径和访问权限，不相信客户端 MIME 或扩展名。
- 日志、错误响应、Audit 和测试输出必须脱敏。
- 发现已提交的真实凭据时，不在聊天或新文档中复制其值；报告路径和类型，建议立即轮换并通过专项修复移除。

## 禁止

- 禁止提交 API Key、Token、Cookie、JWT 密钥、数据库真实密码、微信 AppSecret、支付密钥或云平台 Secret。
- 禁止使用默认 `change-me`、`123456`、`minioadmin` 等值部署生产环境。
- 禁止未经用户确认轮换密钥、调用支付、操作生产数据或部署到外部平台。
- 禁止通过关闭 TLS/鉴权/权限检查来解决开发环境问题。

## 已知风险

当前代码和部署资料存在弱默认值与疑似明文凭据。这些是存量风险，不因本规则自动删改；需单独安全工作项处理密钥轮换、历史清理和配置改造。
