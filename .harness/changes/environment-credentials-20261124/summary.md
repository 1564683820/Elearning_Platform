# 服务端凭据由环境注入

- Audit-ID：environment-credentials-20261124
- 类型：安全与部署配置
- 日期：2026-11-24

## 目标与非目标

- 从服务端配置、MySQL 维护脚本和 Compose 中移除本次排查发现的固定基础设施凭据与应用密钥。
- 密钥轮换、已加密数据迁移、Git 历史清理和在线部署需单独处理。

## 关键决策

- 后端与 MySQL 脚本共用 `Settings`，读取 `server/.env` 和进程环境。应用签名及加密密钥必须非空。
- Compose 通过 `--env-file server/.env` 注入凭据，Redis 与应用共用一个变量，MinIO 与 Milvus 共用一组变量。
- 模板仅保留空的凭据字段。已使用的加密密钥轮换前需要迁移数据库中的加密 API Key。

- Compose 使用测试值验证配置渲染、变量同步和缺失密码时的错误处理。Docker 守护进程在当前环境不可访问，容器和在线服务未启动。
