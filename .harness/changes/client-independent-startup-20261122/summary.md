# 客户端独立启动

- Audit-ID：`client-independent-startup-20261122`
- 类型：架构规则
- 日期：2026-11-22

## 目标与成功标准

- 新增客户端须提供并记录独立启动入口，单端启动无需启动其他客户端。

## 非目标

- H5 和 App 应用另行交付。本次提供启动命令及其设计规则。

## 关键决策

- 客户端可共用后端和公共代码。联合启动复用单端入口，同时运行的客户端应避免端口、运行配置和构建输出冲突。

## 模块级变更

- 在 [架构规则](../../rules/architecture.md) 增加「客户端独立启动」，覆盖现有及未来客户端。
- 新增[根目录 justfile](../../../justfile) 和 [README 命令索引](../../../README.md)。`dev` 在启动前检查 H5 入口，再并行复用两个单端命令。

## 验证与验收

- `./harness.ps1 verify` 退出码为 `0`。Harness 结构检查和 189 个 Python 文件的语法检查通过，Web 类型检查无报错。

## 风险与跳过项

- 当前环境缺少 `just`，且仓库尚无 H5 应用。未验证 `justfile` 实际解析、单端运行、双端运行或退出后的端口释放。
